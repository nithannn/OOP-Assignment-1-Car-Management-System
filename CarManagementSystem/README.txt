# CAR MANAGEMENT SYSTEM
## Java Object-Oriented Programming — Assignment 1

### 1. Project Overview
The Car Management System is a console-based Java application developed to demonstrate the fundamental concepts of Object-Oriented Programming (OOP). It allows users to manage basic information and perform simple operations on a car object.

### 2. Project Files
- `Car.java` — Defines the Car class, including its attributes, constructors, getters, setters and additional methods.
- `CarApp.java` — Contains the main method, accepts user input and provides the menu for interacting with the car object.
- `README.txt` — Provides project information and instructions for compiling and running the application.

### 3. Requirements
- Java Development Kit (JDK)
- Visual Studio Code or another Java-compatible editor
- Terminal or Command Prompt

### 4. How to Compile and Run
1. Open the `CarManagementSystem` folder in Visual Studio Code.
2. Open the integrated terminal in that folder.
3. Compile the Java source files:

   `javac Car.java CarApp.java`

4. Run the application:

   `java CarApp`

### 5. System Features
1. View car details.
2. Update car mileage.
3. Estimate the car's resale value.
4. Check the example service threshold.
5. Change the car's availability.
6. Exit the application.

### 6. Sample Test Data
The following values can be used to test the application:

- Brand: Proton
- Model: X50

- Price: RM90,000
- Mileage: 12,000 km
- Fuel type: Petrol
- Availability: Yes

### 7. Object-Oriented Programming Concepts
The project demonstrates:
- Classes and objects
- Encapsulation through private attributes
- Default and parameterized constructors
- Getters and setters
- Methods and object interaction
- Selection and looping structures

### 8. Limitations
The resale value calculation and service threshold are simplified examples for educational purposes. The application manages one car object during a session and does not permanently save data after the program exits.

### 9. Conclusion
This project demonstrates the practical application of Java OOP concepts through a simple Car Management System. It provides an opportunity to understand how classes, objects, encapsulation, constructors, methods and control structures work together in a console-based application.
