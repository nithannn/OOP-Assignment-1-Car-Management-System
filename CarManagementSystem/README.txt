CAR MANAGEMENT SYSTEM - JAVA OOP ASSIGNMENT 1

Files:
- Car.java: Car object class
- CarApp.java: main program
- README.txt: these instructions

Open this folder in VS Code, then in Terminal run:
javac Car.java CarApp.java
java CarApp

Test with:
Brand: Proton
Model: X50
Year: 2025
Price: 90000
Mileage: 12000
Fuel type: Petrol
Available: yes

Menu:
1 view details; 2 update mileage; 3 estimate resale value;
4 check service threshold; 5 toggle availability; 6 exit.

The resale calculation and service threshold are simplified examples for learning.
The program keeps data only while it is running; it does not save data after exit.
